  <action>
Create `backend/options.py` with three public functions:

**1. `compute_payoff(legs, price_range)`**
- `legs`: list of dicts `{type: "call"|"put", strike: float, premium: float, position: "long"|"short", quantity: int}`
- `price_range`: list of floats (underlying prices at expiry, e.g. 50 steps from 0.5*min_strike to 1.5*max_strike)
- Returns dict `{prices: [...], payoff: [...]}` where payoff[i] = sum of each leg's P&L at prices[i]
- Per-leg P&L: call long = max(S - K, 0) - premium; call short = premium - max(S - K, 0); put long = max(K - S, 0) - premium; put short = premium - max(K - S, 0); multiply by quantity
- price_range may be omitted by caller — if None, generate 200 points from 0.5*min_strike to 1.5*max_strike

**2. `bs_call_price(S, K, T, r, sigma)`**
- Standard Black-Scholes European call: d1 = (ln(S/K) + (r + 0.5*sigma^2)*T) / (sigma*sqrt(T)); d2 = d1 - sigma*sqrt(T); price = S*N(d1) - K*exp(-r*T)*N(d2)
- Use `scipy.stats.norm.cdf` for N(). scipy is already a transitive dependency via numpy/yfinance.
- Returns float. Raise ValueError if T <= 0 or sigma <= 0 or S <= 0 or K <= 0.

**3. `mc_call_price(S, K, T, r, sigma, num_simulacoes=10_000)`**
- Risk-neutral MC pricer: drift = r - 0.5*sigma^2 per step (NOT historical mu — this is OPT-03)
- Steps = int(round(T * 252)) — trading days in horizon T (years)
- Generate paths: shocks = rng.normal(loc=drift/252, scale=sigma/sqrt(252), size=(steps, num_simulacoes)); ST = S * cumprod(exp(shocks), axis=0)[-1]
- Price = exp(-r*T) * mean(max(ST - K, 0)) using np.maximum
- Returns float

Add module docstring explaining OPT-03 design decision: "Risk-neutral drift (r - 0.5*sigma^2) is used instead of historical mu because derivatives must be priced under the risk-neutral measure. Historical drift is irrelevant to no-arbitrage pricing."

```python
class OptionLeg(BaseModel):
    type: str        # "call" | "put"
    strike: float
    premium: float
    position: str    # "long" | "short"
    quantity: int = 1

class PayoffRequest(BaseModel):
    legs: list[OptionLeg]

class BSPriceRequest(BaseModel):
    S: float          # current underlying price
    K: float          # strike
    T: float          # time to expiry in years
    r: float          # risk-free rate (annualized)
    sigma: float      # volatility (annualized)

class MCPriceRequest(BaseModel):
    S: float
    K: float
    T: float
    r: float
    sigma: float
    num_simulacoes: int = 10_000
```

**Routes** (add after simulations section, label with `# ── Options & Pricing ─────`):

```python
@app.post("/api/options/payoff")
async def options_payoff(
    body: PayoffRequest,
    user: Annotated[dict, Depends(get_current_user)],
):
    """OPT-01: Compute combined payoff for a multi-leg options strategy."""
    legs = [leg.model_dump() for leg in body.legs]
    result = compute_payoff(legs, price_range=None)
    return result

@app.post("/api/options/bs-price")
async def options_bs_price(
    body: BSPriceRequest,
    user: Annotated[dict, Depends(get_current_user)],
):
    """OPT-02: Black-Scholes European call price with user-supplied sigma."""
    try:
        price = bs_call_price(S=body.S, K=body.K, T=body.T, r=body.r, sigma=body.sigma)
    except ValueError as e:
        raise HTTPException(status_code=400, detail=str(e))
    return {"price": price, "S": body.S, "K": body.K, "T": body.T, "r": body.r, "sigma": body.sigma}

@app.post("/api/options/mc-price")
async def options_mc_price(
    body: MCPriceRequest,
    user: Annotated[dict, Depends(get_current_user)],
):
    """OPT-03: Risk-neutral MC European call pricer."""
    try:
        price = mc_call_price(
            S=body.S, K=body.K, T=body.T, r=body.r,
            sigma=body.sigma, num_simulacoes=body.num_simulacoes,
        )
    except ValueError as e:
        raise HTTPException(status_code=400, detail=str(e))
    return {"price": price, "S": body.S, "K": body.K, "T": body.T, "r": body.r, "sigma": body.sigma}
```
