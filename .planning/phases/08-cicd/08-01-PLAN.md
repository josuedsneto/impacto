# Phase 8: CI/CD & Polish

## Objective
Auto-deploy on every merge to main; persist user's dark/light theme across browser sessions.

## What was built
- `.github/workflows/deploy.yml`: GitHub Actions SSH deploy on push to main using appleboy/ssh-action@v1.0.3. Requires secrets: VM_HOST, VM_USER, VM_SSH_KEY. Deploy steps: git pull, npm ci + build, pip install, pm2 restart.
- `frontend/components/ThemeProvider.tsx`: React context provider; reads/writes localStorage('theme'). Initializes as "dark" then syncs in useEffect (FOUC cosmetic issue, addressed in Phase 10).
