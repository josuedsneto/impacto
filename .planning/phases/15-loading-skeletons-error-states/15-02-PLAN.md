**AcucarForm.tsx** (model: `frontend/components/regression/DolarForm.tsx`):

Define and export interfaces:
```typescript
export interface AcucarDefaults {
  sb_f: number | null;
  usdbrl: number | null;
  cl_f: number | null;
  estoque_inicial: number | null;
  producao: number | null;
  demanda: number | null;
  estoque_final: number | null;
  estoque_uso_pct: number | null;
}

export interface HistoricoPoint {
  year: number;
  sb_f_real: number;
  sb_f_previsto: number;
}

export interface AcucarResult {
  sb_f_previsto: number;
  sb_f_min: number;
  sb_f_max: number;
  r2: number;
  rmse: number;
  historico: HistoricoPoint[];
}
```

Form state: one string state per numeric input field (same pattern as DolarForm), plus `modelType` state (string, default `"ridge"`).

On defaults load (useEffect on `defaults` prop), populate all 7 numeric fields (estoque_inicial, producao, demanda, estoque_final, estoque_uso_pct, usdbrl, cl_f). Do NOT populate sb_f — that is the target variable.

Form layout: 3-column grid for the 5 supply/demand inputs (estoque_inicial, producao, demanda, estoque_final, estoque_uso_pct), then a row for usdbrl and cl_f, then a native `<select>` with Tailwind classes `"block w-full rounded-md border border-input bg-background px-3 py-2 text-sm"` to choose Ridge vs XGBoost:
- `<option value="ridge">Ridge Regression</option>`
