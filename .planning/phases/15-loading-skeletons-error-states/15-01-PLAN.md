**`run_acucar_regression(inputs: dict, model_type: str = "ridge") -> dict`:**

Inputs dict keys: `estoque_inicial`, `producao`, `demanda`, `estoque_final`, `estoque_uso_pct`, `usdbrl`, `cl_f`

Feature columns (in this order): `["estoque_inicial", "producao", "demanda", "estoque_final", "estoque_uso_pct", "usdbrl", "cl_f"]`

Training:
- `df = fetch_acucar_history()`
- `y = df["sb_f"].values`; `X = df[feature_cols].values`
- If `model_type == "ridge"`: use `sklearn.linear_model.RidgeCV(alphas=[0.1,1.0,10.0,100.0])` — fit on X, y
- If `model_type == "xgboost"`: use `xgboost.XGBRegressor(n_estimators=100, max_depth=3, learning_rate=0.1, random_state=42, n_jobs=1)` — fit on X, y
- For uncertainty range: compute residuals = y - model.predict(X); `std_residuals = np.std(residuals)`
  - `sb_f_previsto = float(model.predict(input_array)[0])`
  - `sb_f_min = sb_f_previsto - 1.96 * std_residuals`
  - `sb_f_max = sb_f_previsto + 1.96 * std_residuals`
- Compute R² via `sklearn.metrics.r2_score(y, model.predict(X))`
- Compute RMSE via `sklearn.metrics.mean_squared_error(y, model.predict(X), squared=False)` — if `squared` param not supported (sklearn >= 1.4 uses `np.sqrt(mse)` instead), use `np.sqrt(mean_squared_error(y, model.predict(X)))`
- Also return `historico`: list of dicts with `year` (int) and `sb_f_real` (float) and `sb_f_previsto` (float) for each training row, for the frontend chart
- Return: `{sb_f_previsto, sb_f_min, sb_f_max, r2, rmse, historico}` — all floats rounded to 4 decimal places except historico

**Add POST /api/regression/acucar/run** route:
```python
@app.post("/api/regression/acucar/run")
@limiter.limit("10/minute")
async def acucar_run(
    request: Request,
    body: AcucarRunRequest,
    user: Annotated[dict, Depends(get_current_user)],
):
    import asyncio
    loop = asyncio.get_event_loop()
    inputs = body.model_dump(exclude={"model"})
    try:
        resultado = await loop.run_in_executor(
            None, lambda: run_acucar_regression(inputs, model_type=body.model)
        )
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc))

    supa = create_client(
        os.environ["SUPABASE_URL"],
        os.environ["SUPABASE_SERVICE_ROLE_KEY"],
    )
    supa.table("regression_runs").insert({
        "user_id": str(user["sub"]),
        "tipo": "acucar",
        "inputs": {**inputs, "model": body.model},
        "resultado": {
            "sb_f_previsto": resultado["sb_f_previsto"],
            "sb_f_min": resultado["sb_f_min"],
            "sb_f_max": resultado["sb_f_max"],
            "r2": resultado["r2"],
            "rmse": resultado["rmse"],
        },
    }).execute()

    return resultado
```

Note: `historico` is returned in the response to the frontend (for the chart) but NOT stored in the DB resultado (to keep the DB payload lean). The in-memory `resultado` dict from `run_acucar_regression` already contains `historico` — do not strip it from the return value; only exclude it from the DB insert.
