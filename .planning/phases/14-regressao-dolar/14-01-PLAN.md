**Environment variables consumed:**
- `FRED_API_KEY` — FRED API key (add to backend .env.example and document in user_setup)

**Function `get_dolar_defaults() -> dict`:**
- Fetch latest values for BCB series via `python-bcb` SGS endpoint:
  - 432 → `selic` (Selic meta rate, % a.a.)
  - 1837 → `m2_bcb` (M2 monetary aggregate, R$ bi)
  - 21859 → `prod_industrial` (Industrial Production index)
- Fetch latest values for FRED series via `requests.get`:
  - FEDFUNDS → `fed_funds`
  - M2SL → `m2_fred` (US M2, billions USD)
  - INDPRO → `indpro` (US Industrial Production)
- FRED base URL: `https://api.stlouisfed.org/fred/series/observations?series_id={sid}&api_key={key}&sort_order=desc&limit=1&file_type=json`
- Return dict with keys: `selic`, `m2_bcb`, `prod_industrial`, `fed_funds`, `m2_fred`, `indpro`
- On any fetch failure, return `None` for that key (never raise — frontend tolerates nulls)

**Function `fetch_dolar_history(months: int = 60) -> pd.DataFrame`:**
- Fetch monthly series from BCB (432, 1837, 21859) for the last `months` months
- Fetch monthly FRED series (FEDFUNDS, M2SL, INDPRO) with `observation_start` = today minus months
- Merge all series on a monthly date index using `pd.merge` on year+month, dropping rows with any NaN
- Also fetch USDBRL=X monthly close from yfinance as the target variable `taxa_dolar`
- Return DataFrame with columns: `taxa_dolar`, `selic`, `m2_bcb`, `prod_industrial`, `fed_funds`, `m2_fred`, `indpro`
- Raise `ValueError("Dados insuficientes: menos de 24 meses após merge")` if fewer than 24 rows after merge

**Function `run_dolar_regression(inputs: dict) -> dict`:**
- Inputs dict keys: `selic`, `m2_bcb`, `prod_industrial`, `fed_funds`, `m2_fred`, `indpro` (floats)
- Call `fetch_dolar_history(months=60)` to get training data
- Fit OLS via `statsmodels.api.OLS(endog=y, exog=sm.add_constant(X)).fit()`
- Predict `taxa_prevista` using the user's input dict (wrapped in a single-row DataFrame)
- Compute `rmse` as `np.sqrt(mean_squared_error(y, fitted.fittedvalues))` (use `sklearn.metrics.mean_squared_error`)
- Compute `correlacao` as `df.corr().round(4).to_dict()` (full correlation matrix of features + target)
- Return:
  ```python
  {
      "taxa_prevista": float,
      "r2": float,           # fitted.rsquared
      "rmse": float,
      "coeficientes": dict,  # {param_name: coef} from fitted.params.to_dict()
      "correlacao": dict,    # nested dict from df.corr()
  }
  ```

Dependencies needed: `statsmodels` (already in requirements.txt), `scikit-learn` (add to backend/requirements.txt as `scikit-learn>=1.4.0`), `python-bcb` (already in requirements.txt), `yfinance` (already in requirements.txt).

**Route 1 — GET /api/regression/dolar/defaults:**

```python
@app.get("/api/regression/dolar/defaults")
@limiter.limit("20/minute")
async def dolar_defaults(request: Request, user: Annotated[dict, Depends(get_current_user)]):
    """Returns latest BCB + FRED values to pre-fill the frontend inputs."""
    import asyncio
    loop = asyncio.get_event_loop()
    defaults = await loop.run_in_executor(None, get_dolar_defaults)
    return defaults
```

**Route 2 — POST /api/regression/dolar/run:**
```python
@app.post("/api/regression/dolar/run")
@limiter.limit("10/minute")
async def dolar_run(
    request: Request,
    body: DolarRegressionRequest,
    user: Annotated[dict, Depends(get_current_user)],
):
    """
    Trains OLS on BCB+FRED history, predicts taxa_dolar for user inputs,
    persists run to regression_runs, returns regression metrics.
    """
    import asyncio
    loop = asyncio.get_event_loop()
    try:
        resultado = await loop.run_in_executor(None, run_dolar_regression, body.model_dump())
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc))
    except Exception as exc:
        logger.error("dolar_run error: %s", exc)
        raise HTTPException(status_code=500, detail="Erro ao executar regressão.")

    # Persist to Supabase
    supa = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SERVICE_KEY"])
    supa.table("regression_runs").insert({
        "user_id": user["id"],
        "tipo": "dolar",
        "inputs": body.model_dump(),
        "resultado": resultado,
    }).execute()

    return resultado
```
