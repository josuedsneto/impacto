  <files>frontend/components/admin/SuggestionQueue.tsx</files>
  <action>
Create `frontend/components/admin/SuggestionQueue.tsx` as a "use client" component.

Follow the exact patterns from TickerSuggestForm.tsx and the market page:
- getAccessToken() inline via createBrowserClient from @supabase/ssr (same pattern as market page)
- BACKEND_URL from process.env.NEXT_PUBLIC_BACKEND_URL ?? "http://localhost:8000"
- toast from "sonner" for feedback

State:
- suggestions: Suggestion[] (array of rows from GET /api/admin/suggestions?status=pending)
- loading: boolean (initial fetch)
- rejectNote: Record<string, string> — keyed by suggestion id, value is the textarea content
- actionLoading: Record<string, boolean> — keyed by suggestion id, true while PATCH in flight

Type Suggestion:
```ts
interface Suggestion {
  id: string;
  ticker: string;
  nome: string;
  tipo: string;
  status: string;
  backfill_status: string;
  review_note: string | null;
  adicionado_por: string | null;
  created_at: string;
}
```

On mount (useEffect with empty dep array): fetch GET `/api/admin/suggestions?status=pending`, set suggestions, handle errors via toast.error.

handleApprove(id, ticker):
- Set actionLoading[id] = true
- PATCH `/api/admin/suggestions/${id}` with body `{ action: "approve" }`
- On success: toast.success(`Ticker '${ticker}' aprovado. Backfill iniciado.`), remove item from suggestions list (filter out by id)
- On error: toast.error(data.detail ?? "Erro ao aprovar.")
- Always clear actionLoading[id]

handleReject(id, ticker):
- note = rejectNote[id] ?? ""
- Set actionLoading[id] = true
- PATCH `/api/admin/suggestions/${id}` with body `{ action: "reject", review_note: note }`
- On success: toast.success(`Ticker '${ticker}' rejeitado.`), remove item from suggestions list
- On error: toast.error(data.detail ?? "Erro ao rejeitar.")
- Always clear actionLoading[id]

UI structure:
- If loading: show "Carregando sugestões..."
- If suggestions empty (and not loading): show "Nenhuma sugestão pendente."
- Else: render a table with columns: Ticker | Nome | Tipo | Sugerido em | Ações
- For each row, Ações column contains:
  - A textarea (className="border rounded p-1 text-sm w-40 resize-none") for the reject note, value=rejectNote[id], onChange updates rejectNote[id], placeholder="Nota (opcional)"
  - Button "Aprovar" (variant "default", size "sm") — calls handleApprove; disabled while actionLoading[id]
  - Button "Rejeitar" (variant "destructive", size "sm") — calls handleReject; disabled while actionLoading[id]

Use Card, CardHeader, CardTitle, CardContent from @/components/ui/card and Button from @/components/ui/button. Do NOT import Input — use a native textarea to avoid adding a component.

Export: `export function SuggestionQueue()`
