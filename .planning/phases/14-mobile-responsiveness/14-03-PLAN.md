  <action>
    For each file listed, wrap the existing `<ResponsiveContainer>` in a `<div>` with Tailwind height classes, then change `height={N}` to `height="100%"`. Read each file before editing to find the exact current JSX.

    **Pattern to apply (for ALL 8 instances):**
    Before:
    ```tsx
    <ResponsiveContainer width="100%" height={N}>
      {/* chart */}
    </ResponsiveContainer>
    ```
    After:
    ```tsx
    <div className="h-[Xpx] md:h-[Npx]">
      <ResponsiveContainer width="100%" height="100%">
        {/* chart — unchanged */}
      </ResponsiveContainer>
    </div>
    ```

    **Per-file mobile/desktop heights (from research):**

    | File | Current height | Mobile class | Desktop class |
    |------|---------------|--------------|---------------|
    | `FanChart.tsx` | 400 | `h-[260px]` | `md:h-[400px]` |
    | `cenarios/page.tsx` | 260 | `h-[220px]` | `md:h-[260px]` |
    | `arima/page.tsx` | 360 | `h-[240px]` | `md:h-[360px]` |
    | `jump-diffusion/page.tsx` | 320 | `h-[240px]` | `md:h-[320px]` |
    | `metas/page.tsx` | 320 | `h-[240px]` | `md:h-[320px]` |
    | `risco/page.tsx` | 200 | `h-[180px]` | `md:h-[200px]` |
    | `volatilidade/page.tsx` | 260 | `h-[200px]` | `md:h-[260px]` |
    | `PayoffChart.tsx` | 350 | `h-[240px]` | `md:h-[350px]` |

    Critical rules:
    - The wrapper `<div>` must be added OUTSIDE `<ResponsiveContainer>`, not inside it
    - `height="100%"` on `ResponsiveContainer` only works because the wrapper div now has an explicit height
    - Do not add `width` constraints to the wrapper div — width is controlled by `ResponsiveContainer width="100%"`
    - If a file has margin or padding applied to the current `ResponsiveContainer` parent, keep it on the outer container, not on the new wrapper div
    - If `cenarios/page.tsx` already has a wrapping div from Task 1 changes, nest the new height div correctly inside the chart rendering block (not the stats grid)
