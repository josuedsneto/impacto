       class RequestIDMiddleware(BaseHTTPMiddleware):
           async def dispatch(self, request: Request, call_next):
               request_id = str(uuid.uuid4())
               request.state.request_id = request_id
               response = await call_next(request)
               response.headers["X-Request-ID"] = request_id
               return response

    3. After `app.add_middleware(SlowAPIMiddleware)` and the existing CORSMiddleware registration, add RequestIDMiddleware registration LAST (so it executes FIRST — Starlette processes middleware LIFO):
       app.add_middleware(RequestIDMiddleware)

       Final middleware registration order in file (top to bottom):
         app.add_middleware(SlowAPIMiddleware)
         app.add_middleware(CORSMiddleware, ...)
         app.add_middleware(RequestIDMiddleware)   # ← add here

    4. After all middleware registrations (before the @app.get("/api/health") route), add the two exception handlers in this exact order — RateLimitExceeded BEFORE Exception:

       from fastapi.responses import JSONResponse

       @app.exception_handler(RateLimitExceeded)
       async def rate_limit_handler(request: Request, exc: RateLimitExceeded) -> JSONResponse:
           request_id = getattr(request.state, "request_id", "unknown")
           logger.warning(
               "Rate limit exceeded | request_id={} path={}",
               request_id, request.url.path
           )
           return JSONResponse(
               status_code=429,
               content={"error": "Muitas requisições. Aguarde e tente novamente.", "code": "RATE_LIMITED"},
               headers={"X-Request-ID": request_id},
           )

       @app.exception_handler(Exception)
       async def global_exception_handler(request: Request, exc: Exception) -> JSONResponse:
           request_id = getattr(request.state, "request_id", "unknown")
           logger.opt(exception=exc).error(
               "Unhandled exception | request_id={} path={} method={}",
               request_id, request.url.path, request.method
           )
           return JSONResponse(
               status_code=500,
               content={"error": "Erro interno do servidor.", "code": "INTERNAL_ERROR"},
               headers={"X-Request-ID": request_id},
           )

    CRITICAL: Do NOT include str(exc), repr(exc), or traceback.format_exc() anywhere in the JSON content returned to the client (SEC-02). The exception is logged server-side only.

    NOTE: `JSONResponse` may already be imported via `from fastapi.responses import JSONResponse` or via fastapi directly. Check and avoid duplicate import.

    NOTE: `RateLimitExceeded` is already imported at the top of main.py — do not add a duplicate import.
