**`frontend/app/app/atr/page.tsx`**

Seguir o mesmo padrão de `frontend/app/app/regressao-acucar/page.tsx`: "use client", useState/useEffect, Tabs shadcn, getAccessToken inline.

Estados: `usinas` (Usina[]), `usinasLoading`, `usinasError`, `activeResult` (AtrResult|null), `historico` (HistoricoItem[]), `historicoLoaded`, `historicoLoading`, `historicoError`, `activeTab`, `currentUserId` (string — buscar via `supabase.auth.getSession().data.session?.user.id`).

**useEffect no mount:** Chamar GET `/api/atr/usinas` para popular lista de usinas. Ao mesmo tempo buscar currentUserId via createBrowserClient.

**handleTabChange:** Ao ativar "historico", se não carregado, buscar GET `/api/atr/historico?usina_id={usinaId}` (usando a usina atualmente selecionada no form — passar como estado para a página).

**handleResult(result: AtrResult):** Setar `activeResult`. Também invalidar historico (setar `historicoLoaded = false`) para que na próxima vez que o usuário abrir a aba seja recarregado com o novo ponto.

**handleToggleShare(id: string, compartilhado: boolean):** PATCH `/api/atr/simulacoes/${id}/compartilhar` com `{ compartilhado }`. Em sucesso, atualizar o item correspondente em `historico` (setState imutável).

Layout:
```tsx
<div className="container mx-auto py-8 space-y-6">
  <h1 className="text-2xl font-semibold">ATR — Açúcar Total Recuperável</h1>
  {usinasError && <p className="text-sm text-red-600">{usinasError}</p>}
  <Tabs value={activeTab} onValueChange={handleTabChange}>
    <TabsList>
      <TabsTrigger value="simular">Simular</TabsTrigger>
      <TabsTrigger value="historico">Histórico</TabsTrigger>
    </TabsList>
    <TabsContent value="simular" className="space-y-6 mt-6">
      {usinasLoading ? <p ...>Carregando usinas...</p> : (
        <AtrForm usinas={usinas} onResult={handleResult} onUsinaChange={setSelectedUsinaId} />
      )}
      {activeResult && (
        <AtrMetrics result={activeResult} />
      )}
    </TabsContent>
    <TabsContent value="historico" className="mt-6">
      {/* loading/error/empty states como padrão regressao-acucar */}
      {!historicoLoading && historico.length > 0 && (
        <AtrHistorico historico={historico} onToggleShare={handleToggleShare} currentUserId={currentUserId ?? ""} />
      )}
    </TabsContent>
  </Tabs>
</div>
```

Nota: AtrForm precisa aceitar prop adicional `onUsinaChange: (id: string) => void` para que a página saiba qual usina está selecionada quando o usuário muda para a aba Histórico. Atualizar a interface de AtrForm para incluir essa prop opcionalmente.
