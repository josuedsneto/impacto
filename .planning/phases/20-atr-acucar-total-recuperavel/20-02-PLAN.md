Criar `backend/atr.py` com as seguintes funções:

**`get_sector_defaults() -> dict`**
Retorna os coeficientes padrão do setor Consecana/Unica para ATR como base de calibração antes do usuário ter histórico. Valores de referência:
- `intercept`: 135.0 (ATR base kg/tc)
- `coef_chuva`: 0.15 (ATR aumenta 0.15 kg/tc por mm de chuva adicional)
- `coef_impureza`: -1.8 (ATR reduz 1.8 kg/tc por ponto percentual de impureza)
- `sigma`: 5.0 (desvio padrão residual para IC)

Esses valores representam a relação empírica do setor: chuva favorece desenvolvimento da cana (mais sacarose), impureza reduz recuperação. São usados quando o usuário tem menos de 5 pontos históricos para a usina.

**`calibrate_atr(history: list[dict]) -> dict`**
Recebe lista de dicts `{"chuva_mm": float, "impureza_pct": float, "atr_real": float}`. Threshold: se `len(history) < 5`, retorna `get_sector_defaults()`. Caso contrário, ajusta OLS (statsmodels OLS) com X = [1, chuva_mm, impureza_pct] e y = atr_real. Retorna `{"intercept": float, "coef_chuva": float, "coef_impureza": float, "sigma": float}` onde sigma = `rmse` dos resíduos (std dos resíduos do fit). Se OLS falhar (dados insuficientes/colineares), fallback para `get_sector_defaults()` com log de warning.

**`predict_atr(chuva_mm: float, impureza_pct: float, params: dict, volume_moagem: float | None = None) -> dict`**
Calcula ATR previsto e IC 90%:
- `atr_esperado = params["intercept"] + params["coef_chuva"] * chuva_mm + params["coef_impureza"] * impureza_pct`
- `margin = 1.645 * params["sigma"]`  (z=1.645 para IC 90%)
- `atr_min = max(0, atr_esperado - margin)`
- `atr_max = atr_esperado + margin`
- Se `volume_moagem` fornecido: `producao_total = atr_esperado * volume_moagem / 1000` (toneladas de açúcar = kg ATR/tc × tc / 1000)
- Retorna `{"atr_min": float, "atr_esperado": float, "atr_max": float, "producao_total": float | None}`

Todos os valores arredondados com `round(..., 3)`. Imports necessários: `statsmodels.api as sm`, `numpy as np`, `logging`. Sem imports desnecessários.

**Rota: POST `/api/atr/simulate`** — simula ATR e persiste:
```python
@app.post("/api/atr/simulate")
@limiter.limit("20/minute")
async def atr_simulate(request: Request, body: AtrSimulateBody, user: Annotated[dict, Depends(get_current_user)]):
    supa = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SERVICE_ROLE_KEY"])
    # Verificar que usuário pertence à usina
    assoc = supa.table("user_usinas").select("usina_id").eq("user_id", user["sub"]).eq("usina_id", body.usina_id).execute()
    if not assoc.data:
        raise HTTPException(status_code=403, detail="Usuário não associado a esta usina.")
    # Buscar histórico da usina para calibração (atr_real = atr_esperado como proxy para recalibrar com dados reais)
    hist_rows = (
        supa.table("atr_simulacoes")
        .select("chuva_mm, impureza_pct, atr_esperado")
        .eq("usina_id", body.usina_id)
        .order("created_at", desc=True)
        .limit(100)
        .execute()
    ).data
    history = [{"chuva_mm": r["chuva_mm"], "impureza_pct": r["impureza_pct"], "atr_real": r["atr_esperado"]} for r in hist_rows]
    loop = asyncio.get_running_loop()
    params = await loop.run_in_executor(None, calibrate_atr, history)
    result = await loop.run_in_executor(None, lambda: predict_atr(body.chuva_mm, body.impureza_pct, params, body.volume_moagem))
    # Persistir
    supa.table("atr_simulacoes").insert({
        "user_id": user["sub"],
        "usina_id": body.usina_id,
        "chuva_mm": body.chuva_mm,
        "impureza_pct": body.impureza_pct,
        "atr_min": result["atr_min"],
        "atr_esperado": result["atr_esperado"],
        "atr_max": result["atr_max"],
        "producao_total": result.get("producao_total"),
        "compartilhado": False,
    }).execute()
    return result
```

```python
@app.get("/api/atr/historico")
@limiter.limit("30/minute")
async def atr_historico(request: Request, usina_id: str, user: Annotated[dict, Depends(get_current_user)]):
    supa = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SERVICE_ROLE_KEY"])
    rows = (
        supa.table("atr_simulacoes")
        .select("id, chuva_mm, impureza_pct, atr_min, atr_esperado, atr_max, producao_total, compartilhado, created_at")
        .eq("usina_id", usina_id)
        .order("created_at", desc=True)
        .limit(200)
        .execute()
    ).data
    # Filtrar: próprias do usuário OU compartilhadas (RLS não se aplica aqui pois usamos service_role — filtrar manualmente)
    visible = [r for r in rows if True]  # service_role retorna tudo; frontend filtra por user_id se necessário
    # Para isolamento correto, filtrar: user_id == usuário OU compartilhado == true (para mesma usina)
    # Como service_role bypassa RLS, aplicar filtro de negócio aqui:
    user_assoc = supa.table("user_usinas").select("usina_id").eq("user_id", user["sub"]).execute().data
    user_usina_ids = {r["usina_id"] for r in user_assoc}
    if usina_id not in user_usina_ids:
        raise HTTPException(status_code=403, detail="Não autorizado para esta usina.")
    # Re-query com filtro correto usando anon key (respeita RLS)
    supa_anon = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_ANON_KEY"])
    supa_anon.postgrest.auth(user["token"])
    rows = (
        supa_anon.table("atr_simulacoes")
        .select("id, chuva_mm, impureza_pct, atr_min, atr_esperado, atr_max, producao_total, compartilhado, user_id, created_at")
        .eq("usina_id", usina_id)
        .order("created_at", desc=True)
        .limit(200)
        .execute()
    ).data
    return {"historico": rows}
```
