State:
- `ticker: string` — currently selected ticker, starts as "SB=F"
- `volatilidade: string` — controlled input value
- `taxaLivreRisco: string` — controlled input value
- `pctBound: string` — controlled input value
- `loading: boolean` — loading saved params
- `saving: boolean` — save in progress
- `saved: boolean` — show success message
- `error: string | null` — show error message

Ticker options: ["SB=F", "USDBRL=X"] — rendered as a `<select>` element.

getAccessToken: same pattern as simulation/page.tsx (createBrowserClient + getSession).

loadParams (async, called on ticker change):
- Reset form fields to empty string, set loading=true, error=null, saved=false.
- GET `${API}/api/params/${ticker}` with Bearer token.
- If 200: populate volatilidade, taxaLivreRisco, pctBound from response (convert to string, empty string if null).
- If 404: leave fields empty (new ticker, no params saved yet).
- If other error: set error from response detail.
- Always set loading=false.

useEffect([ticker]): call loadParams when ticker changes. Run on mount.

handleSave (async):
- Set saving=true, error=null, saved=false.
- Build body: parse each field to float. If empty string, omit (do not send null — send only defined fields).
- If all three are empty, set error="Preencha ao menos um campo." return.
- PUT `${API}/api/params/${ticker}` with JSON body containing only non-empty fields.
- On success: set saved=true. On error: set error from response detail.
- Always set saving=false in finally.

Render:
- Heading: "Parâmetros por Ativo" (text-lg font-semibold)
- Ticker select: label "Ativo", select element with options SB=F and USDBRL=X.
- Three numeric inputs using components/ui/input.tsx (native HTML wrapper):
  - "Volatilidade customizada (0–5)" → type="number" step="0.01" min="0" max="5"
  - "Taxa livre de risco (-0.5–1)" → type="number" step="0.001" min="-0.5" max="1"
  - "PCT Bound preferido (0.05–2)" → type="number" step="0.01" min="0.05" max="2"
- Save button (using components/ui/button.tsx). Disabled while saving or loading.
- Show loading text "Carregando..." while loading.
- Show success "Parâmetros salvos com sucesso." (text-green-600) when saved=true.
- Show error text in text-red-600 when error is set.
