## Actionable Fixes (by severity)

### 1. ENV VAR SPLIT — blocks ADM + MKT-03 in production
`SuggestionQueue.tsx`, `TickerSuggestForm.tsx`, `app/app/market/page.tsx` use `NEXT_PUBLIC_BACKEND_URL` (undocumented). Every other component uses `NEXT_PUBLIC_API_URL`. In production, these three fall back to `localhost:8000`, failing with connection refused.
**Fix:** Align the three files to `NEXT_PUBLIC_API_URL` OR document and provision `NEXT_PUBLIC_BACKEND_URL`.

### 2. HISTORY SHAPE MISMATCH — breaks SIM-02, SIM-03
`simulation/page.tsx` line 78: `setHistory(data as HistorySummary[])` — GET /api/simulations returns `{"simulations": [...]}`.
**Fix:** `setHistory((data as { simulations: HistorySummary[] }).simulations)`

### 3. PARAMS NOT CONSUMED — PARAM-01, PARAM-02 half-complete
`SimulationForm.tsx` always initializes with hardcoded defaults. Saved `pct_bound`, `volatilidade_custom`, `taxa_livre_risco` are never read.
**Fix:** Add `useEffect([ticker])` in SimulationForm to fetch `GET /api/params/{ticker}` and pre-fill form defaults.

### 4. ADMIN ROLE CHECK — cosmetic UX (not a security breach)
`/app/admin/page.tsx` checks auth but not role. Non-admins see the page before API returns 403.
**Fix:** Read `app_metadata.role` from session, redirect non-admins before rendering `SuggestionQueue`.

### 5. Phase 8 — INFRA-03, INFRA-04 never built
GitHub Actions CI/CD and dark/light theme persistence were planned but Phase 8 was never executed.
**Fix:** Execute Phase 8 or accept as v2.0 scope.
