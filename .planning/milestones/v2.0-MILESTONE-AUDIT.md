## Critical Gaps (Blockers)

### MKT-03 — Ticker Suggest DB Write Broken

**Files:** `backend/main.py` (line 132), `backend/main.py` (TickerSuggestRequest model), `supabase/migrations/20260320000003_tickers_catalog.sql`

**Bug 1 — Column name mismatch:**
```python
# main.py line 132 (WRONG)
"suggested_by": user["id"]

# Should be (matches DB schema)
"adicionado_por": user["id"]
```

**Bug 2 — tipo CHECK constraint violation:**
```python
# TickerSuggestRequest model (WRONG)
tipo: str = "equity"  # equity | futures | fx | etf | crypto

# DB constraint only allows:
CHECK (tipo IN ('commodity', 'fx', 'acao', 'indice'))
```
Every default ticker suggestion fails with a Postgres constraint violation. The `tipo` enum in the model and frontend is completely misaligned with the schema.

**Fix required:**
1. `main.py` line 132: `"suggested_by"` → `"adicionado_por"`
2. `TickerSuggestRequest.tipo` default + enum: align with `('commodity', 'fx', 'acao', 'indice')`
3. Frontend `TickerSuggestForm.tsx`: update tipo dropdown options to match schema values
