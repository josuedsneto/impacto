# Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder `app/page.tsx` with a polished public landing page featuring a split hero (text + sugarcane aerial photo), floating live-price cards (decorative), and a stats bar — with correct links to `/login` and an auth redirect to `/app/dashboard` for logged-in users.

**Architecture:** Single async Server Component (`app/page.tsx`) that checks Supabase session and redirects if authenticated, then renders a fully static marketing page. No client-side JS required. Image served from `public/` via Next.js `<Image>`.

**Tech Stack:** Next.js App Router, Supabase SSR (`createServerSupabaseClient`), `next/image`, `next/link`, Tailwind CSS inline styles
